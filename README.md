# 🧱 AppBuilder – Construa Layouts Visuais com Liberdade

O **AppBuilder** é uma ferramenta visual interativa feita para desenvolvedores e designers que desejam criar, testar e ajustar visuais de aplicativos baseados em PyQt de forma rápida e precisa.

Com ele, você pode:
- Visualizar e posicionar elementos como botões, labels e caixas com arrastar-e-soltar.
- Escolher estilos personalizados (cores, fontes, bordas).
- Gerar automaticamente o código PyQt correspondente ao layout criado.
- Salvar presets de tema e estilo.
